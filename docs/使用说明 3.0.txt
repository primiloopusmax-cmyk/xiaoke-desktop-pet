小克桌宠 3.0 · 使用说明

【怎么启动】
  双击 XiaoKe.exe。第一次启动她会简单问三步（怎么称呼你 / 你在哪儿 / 兴趣与作息），都可以跳过，以后在「设置 → 我的资料」里改。
  启动前请先退出旧版小克（托盘图标 → 退出小克），两个版本共用同一份数据文件夹，同时只能开一个。
  旧版填过的 API 密钥和聊天记录会自动带过来。

【怎么和她玩】
  单击她：摸头 / 戳脸 / 碰书 / 点裙子 / 点鞋子……各有反应（连点 8 下会转圈）。
  右键 或 双击：面板，只有四项 —— 聊天 / 互动 / 动作 / 设置。
    聊天：流式逐字回复；输入框回车发送，Shift+回车换行；右上角「收起」只留输入框；可以「停止」「重试」「清空记录」。
          说「记住：我喜欢喝奶茶」她会记下来；说「忘掉：奶茶」就删掉。模型觉得值得记的事会先问你同不同意。
    互动：摸摸头 / 抱抱 / 握手 / 喂她 / 夸她 / 逗她 / 转圈 / 跳舞 / 散步 / 东张西望 / 睡觉 / 今天天气 / 碎碎念 / 查账本 / 回右下角 / 固定 / 免打扰 / 藏起来 / 冷落她。
    动作：80 个动作按 看书 / 吃东西 / 睡觉 / 玩耍 / 心情 / 日常 / 时节 / 事件 分类，点了就做。不点的时候她会按时间、天气、节日、体力自己挑。
          每个动作都是连续的：进场先弹一下，然后一直在动（哼歌摇摆、吃东西一口一口、拉琴运弓、骑木马前后摇、荡秋千摆、冷得发抖、困了点头…），
          隔几秒再来个小动作，音符 / 爱心 / 蒸汽按节奏冒。待机时也会呼吸、换重心、瞟一眼、眨眼。
    设置：单独的设置窗口（也可以从托盘打开）。
  按住拖动：弹簧跟手；快速甩出去松手会飞、撞墙反弹、落地 Q 弹，甩太狠摔晕几秒；飞行中点中她有积分。
  Ctrl + 滚轮：调大小。
  托盘图标：藏起 / 叫出、回右下角、设置、聊天、大小、固定、鼠标穿透、置顶、免打扰、选屏幕、快捷启动、开机自启、退出。

【设置窗口】
  人物与窗口：大小、动作动效（完整 / 轻量 / 关闭）、固定、鼠标穿透、置顶、住在哪个屏幕、回右下角、藏起来、开机自启、人物包。
  模型：服务商（Claude / DeepSeek / 自定义 OpenAI 兼容）、端点、模型名（可「获取列表」）、API 密钥（本机加密保存，不进代码和日志）、「测试连接」。
        用量：本月 token 是服务商返回的真实数字；费用只是按单价估算；余额只有 DeepSeek 能查。
        聊天：带几轮上下文、是否配贴纸、是否按模型给的情绪做表情。
  陪伴：安静 / 适中 / 活泼 三档；免打扰开关 + 每天固定免打扰时段；碎碎念间隔；休息提醒；饭点提醒；早上播天气；系统通知；生日。
  我的资料：称呼、她的语气、所在地（联网查坐标，天气按它查）、时区、兴趣、作息、其他备注。只存本机，聊天时发给你选的模型。
  她记住了什么：长期记忆开关、逐条修改 / 删除 / 手动添加 / 清空；聊天记录单独清空。
  联动：Claude Code hooks 安装 / 卸载 / 演示；本地接口状态；邻居蓝毛开关；快捷启动程序。
  手感：重力 / 弹性 / 摩擦 / 力度 / 顶部反弹，有预设。

【模型密钥去哪申请】
  Claude：console.anthropic.com → API Keys（按用量计费，和 Claude 订阅额度无关）。
  DeepSeek：platform.deepseek.com → API keys。
  自定义：任何 OpenAI 兼容服务，填端点（到 /v1 为止）、模型名、密钥。
  不填密钥她照样会动、会互动，只是聊天只有自带台词。

【本地接口】（给别的程序用，只监听 127.0.0.1，端口 7341，被占用顺延到 7342…；设置 → 联动 里能看到）
  GET  /state                       她现在在干嘛（模式、位置、工作状态、账本、当前模型…）
  POST /say     {"text":"…","ms":8000}
  POST /anim    {"name":"rubik"}     动作 id / 帧名 / spin dance walk turn scared doze read ramen badminton sleep ledger whisper home / 情绪词（开心 生气 难过 惊讶 困 得意 疑惑 饿了 累 庆祝 害羞 爱心）
  POST /chat    {"text":"…"}         走当前模型，回 {text, emotion}
  POST /whisper
  POST /work    {"state":"working","task":"Edit · app.js"}   thinking / working / result / waiting / success / error / null
  POST /notify  {"title":"…","body":"…"}
  例：curl -X POST http://127.0.0.1:7341/say -H "Content-Type: application/json" -d "{\"text\":\"你好呀\"}"

【文件在哪】
  数据：%APPDATA%\小克\  →  config.json（服务商、加密密钥、人物包）/ settings.json（设置）/ profile.json（资料）/ memory.json（长期记忆）/ history.json（聊天记录）
  人物包：resources\app\packs\xiaoke\  →  img\（120 张动作图）/ memes\（贴纸）/ layout.js / masks.js / poses.js（动作表）/ lines.js（台词）/ persona.js（人设）
  复制 packs\xiaoke 改个名、换图和台词，就是一个新角色；在设置里切换。换模型不会换人。
