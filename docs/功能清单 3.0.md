# 小克 3.0 · 功能清单

## 一、已完成

**素材**
- 22 张合图切成 101 个独立动作：去灰底、去格线、去脚下投影、清掉邻格溢出的碎片，保留头发 / 丝带 / 道具；落叶堆等贴边素材做了边缘羽化。
- 发丝之间、胳膊和身体之间漏出的底色小块全部抠掉（按“四周是不是头发 / 描边”判断，裙子上的灰白阴影不会被误抠）；软边颜色取内侧像素而不是反预乘，深色桌面上没有白边；101 张在深色和白色背景上逐张检查过。
- 统一到同一画布（1500×1200，站立身高 901px，脚底线 y=1191，水平居中），切换动作不会忽大忽小。
- 2.2 的 40 张活动图（n100–n414）和看书翻页 / 拉面 / 羽毛球 / 躺睡四个老活动已去掉；保留静置模型本身（待机 + 眨眼 + 同一张原画上的表情和掏枪）以及 12 格那张图上的全部要素：摔倒、扔鞋、扔书、晕倒、转圈四向、正 / 左 / 背 / 右四个朝向。
- 原始图片一张没动，处理结果另存在 `packs/xiaoke/img`；对照表见 `动作素材对照表.md`。
- 非序列动作切换带 160ms 淡入淡出；行走 / 转圈 / 甩飞这类序列硬切。

**动效（让一张图动起来）**
- 自己写的动效引擎 `motion.js`：人物按水平条切成几十条，每一帧按高度给每条不同的位移 / 缩放，一张原画就能弯腰、摆头、呼吸、脖子点头、果冻式晃动、以脚底或吊点为轴摆动，再叠整体平移 / 旋转 / 压扁拉伸；脚底始终不漂。
- 每个动作配了循环动效（哼歌摇摆、吃东西一口一口、拉琴运弓、打字、思考歪头、骑木马前后摇、荡秋千以绳子顶端为轴摆、幽灵漂浮、冷得发抖、困了慢慢点头再惊醒、躺着只做呼吸…）、进场弹一下、起手动作、隔几秒的随机小动作（点头 / 小跳 / 歪头 / 伸懒腰…），特效按节奏持续冒（音符 / 爱心 / 蒸汽 / 花瓣 / Zzz）。
- 待机也在动：呼吸、换重心、瞟一眼、歪头、深夜打哈欠、眨眼；行走有步伐起伏和前倾；被拎起来晃；掏枪时喘气；聊天时思考 / 说话 / 情绪各有一套。
- 脸红 / 汗滴 / 怒号这些叠加件跟着头部一起动；点击命中也按当前位移修正。
- 设置里可选 完整 / 轻量（幅度小、30 帧，省电）/ 关闭（只切画面）；系统「减少动态效果」时自动关闭。

**基础行为（像蓝毛）**
- 待机 / 眨眼 / 东张西望 / 屏幕上散步（方向、距离、速度随大小）/ 随机动作链（按分类权重、时间段、气温、天气、节日标签、体力挑选；同一动作短期不重复；直接互动优先，随机动作播完才换）。
- 点击各部位反应、长按、连点转圈、拖拽弹簧跟手、甩抛物理（重力 / 弹性 / 摩擦 / 顶部反弹可调、有预设）、飞行中点中得分、重摔晕倒、扔鞋扔书、东张西望、吓一跳、站着打瞌睡、冷落掏枪 / 生闷气（安静档和免打扰时不触发）。
- 时节动作：春节 / 元宵 / 端午 / 中秋 / 万圣 / 圣诞 / 复活节 / 情人节 / 樱花 / 落叶 / 雪人 / 围巾…按用户时区的日期与农历自动加权（南半球季节反转）。
- 大小（滑杆 / 预设 / Ctrl+滚轮）、固定位置、鼠标穿透、始终置顶（带 5 秒看门狗）、藏起 / 托盘找回、记住位置、选择住在哪个屏幕、分辨率或显示器变化时自动拉回屏幕内。

**模型接入**
- 人物与模型分开；服务商：Claude（Anthropic Messages API）/ DeepSeek / 自定义 OpenAI 兼容。设置项：服务商、端点、模型（可拉取列表）、API 密钥、测试连接。
- 密钥用 Windows DPAPI 加密存在本机 `config.json`，不写代码、不打日志；界面只显示末 4 位。
- 流式逐字回复（气泡 + 聊天面板同步），停止、重试、清空记录、历史持久化；聊天面板和主面板显示当前服务商 + 模型。
- 错误中文解释：没填密钥 / 密钥不对 / 余额或额度不足 / 限流 / 模型名不对 / 连不上 / 超时 / 端点格式不对，并给「重试」「去模型设置」按钮。
- 没密钥或离线：所有动作、互动、提醒照常，聊天用自带台词并标注「离线自带台词」。

**聊天状态与动作联动**
- 等待时做「思考」姿势 + 常驻气泡；开始回复切「说话」姿势；出错切「疑惑」姿势 + 汗滴。
- 模型可在回复末尾给 `[表情:xx]`（开心 / 害羞 / 爱心 / 生气 / 难过 / 惊讶 / 困 / 得意 / 疑惑 / 饿了 / 累 / 庆祝 / 平静），程序映射到现成动作并带时长，不认识的词当「平静」；标签不会出现在聊天正文里。
- 回复可配贴纸（由全身表情图裁出），可关。

**用户资料与记忆**
- 首次启动三步引导（可跳过、可关），之后在设置里随时改：称呼、她的语气、所在地（联网查坐标）、时区、兴趣、作息、备注。
- 资料 / 聊天记录 / 长期记忆三个文件分开存。
- 长期记忆只来自：用户说「记住：…」、聊天中模型提议后用户点了「记住」、设置里手动添加；「她记住了什么」页可改、可删、可清空、可整体关闭；换模型服务商不丢。
- 人设通用化：不再写死城市和特定游戏，所有个人信息来自资料；台词里的 `{city}` 按资料替换。

**主动陪伴**
- 安静 / 适中 / 活泼三档（碎碎念间隔与概率、休息提醒间隔、是否提醒吃饭）；可单独覆盖碎碎念间隔与休息间隔。
- 每天固定免打扰时段 + 立即免打扰开关：期间不主动说话、不漫游、不掏枪、不弹通知。
- 问候按时间段；休息提醒按连续在电脑前的时长；饭点、睡觉时间（按作息）、早上天气、节日当天各一天一次；碎碎念由模型生成并避开最近 30 句，没密钥用自带台词。
- 天气只用 Open-Meteo 的真实查询；没填所在地或查不到时明确说出来，不编。
- 用户离开电脑 10 分钟、面板打开、她正忙（拖拽 / 飞行 / 掏枪 / 摔倒）时都不主动说话。

**代理联动与用量**
- 普通聊天走模型 API；工作状态来自独立连接：Claude Code hooks（安装到 `~/.claude/settings.json`，先备份；卸载可清除）或本地接口 `POST /work`。只有收到真实事件才显示 思考 / 工作中 / 一步完成 / 等待处理 / 已完成 / 出错；设置里标明「未安装 / 已安装等待事件 / 已连接」。
- 等待确认、完成、出错时弹 Windows 通知（可关；免打扰时段不弹）。
- 本地接口 `/state /say /anim /chat /whisper /work /notify`，只监听本机。
- 用量：token 数取服务商每次返回的真实用量，按服务商分开统计；费用标明「估算」并可改单价；预算六档对应她抱 token 罐子的表情；余额只在服务商提供接口时显示（DeepSeek）。
- 邻居桌宠（DeepSeek 蓝毛）联动保留，可关；未检测到时明确标出。

**界面**
- 白底橙色；右键 / 双击面板只有 聊天 / 互动 / 动作 / 设置；详细设置在独立窗口（中文标签、滑杆、开关、分页，无深层嵌套；按系统缩放自适应）。
- 人物包：`packs/<id>/`（图 + 动作表 + 台词 + 人设 + 清单），设置里切换；切换模型不切人物。

## 二、尚未完成 / 有意没做

- **屏幕或应用感知**：没有加。加的话会提供单独开关并说明读取内容与是否上云；目前她不读取任何屏幕或窗口信息。
- **第二个人物包**：结构和切换都做好了，但目前只有「小克」一个包；复制 `packs/xiaoke` 改图改名即可。
- **真实余额**：只有 DeepSeek 有余额接口；Claude 和多数自定义服务商不提供，界面写明「不提供」。
- **跨屏拖拽**：她一次只住在一个屏幕上（可选哪个），不能从一个屏幕直接拖到另一个。
- **语音**：没有 TTS / 语音输入。
- **自动化测试**：渲染层和设置窗口用 Playwright 做了完整回归（动作切换、面板、流式聊天、标签解析、记忆确认、工作状态、通知、账本、拖拽甩抛、首次引导、设置读写），主进程用模拟 Electron 跑了存储迁移、密钥加密、接口路由、hooks 安装卸载；仓库里暂时没有附带这些测试脚本。遇到问题欢迎提 Issue。

## 三、首次使用需要配置的项目

| 项目 | 在哪 | 说明 |
|---|---|---|
| 模型服务商与密钥 | 设置 → 模型 | 选 Claude / DeepSeek / 自定义，填密钥，点「测试连接」。旧版的 Claude 密钥会自动带过来。 |
| 模型名 | 设置 → 模型 | 默认 claude-haiku-5-5 / deepseek-chat；可「获取列表」后改。 |
| 所在地与时区 | 首次引导 或 设置 → 我的资料 | 填了才有真实天气和按你的时间的问候。 |
| 称呼、语气、兴趣、作息 | 同上 | 影响她怎么叫你、碎碎念聊什么、什么时候提醒睡觉。 |
| 活跃程度与免打扰时段 | 设置 → 陪伴 | 默认适中、23:00–08:00 免打扰。 |
| 月预算与单价 | 设置 → 模型 → 用量 | 费用是估算；默认按 Haiku 5.5 官方单价 $0.10 / $0.50 每百万 token，换模型请自行改。 |
| 生日 | 设置 → 陪伴 | 当天有长寿面。 |
| Claude Code 联动 | 设置 → 联动 → 安装联动 | 装完重启 Claude Code。 |
| 快捷启动 | 设置 → 联动 | 想从托盘一键打开的程序。 |
| 开机自启 | 设置 → 人物与窗口 / 托盘 | 记得把旧版的自启关掉。 |
