动作动效

每个动作都是在原画上做连续的形变（弯腰、摆头、呼吸、果冻式晃动、以脚底为轴的小跳），加上按节奏冒出的音符 / 爱心 / 蒸汽。笔记本电量吃紧时选「轻量」。

窗口

她会记住最后站的位置；换了分辨率 / 显示器拔掉时会自动拉回屏幕里。

人物包

每个人物包是 packs/<名字>/ 一个文件夹：图片、动作表（poses.js）、台词（lines.js）、默认人设（persona.js）。复制一份改图就是新角色。

模型

联动

这些功能需要外部程序配合，没连上时会明确标出来；她只在收到真实事件时才显示工作状态。

Claude Code 联动

读取中…

安装会在 %USERPROFILE%\.claude\settings.json 里加几条 hooks（先备份原文件），Claude Code 干活时把事件发到她的本地端口（只在本机，不联网）：思考 → 敲键盘 → 等你确认（弹通知）→ 完成 / 出错。装完要重启 Claude Code。权限仍由 Claude Code 自己管，她只看不动。

本地接口

读取中…

别的程序（比如你自己的代理）可以调用：GET /state、POST /say {text}、POST /anim {name}、POST /chat {text}、POST /work {state,task}（state：thinking / working / result / waiting / success / error / null）、POST /notify {title,body}。只接受本机连接。
